## 已落地的修复

1. `update_activity_plan` 保持 Draft/Paused/非 uncertain Blocked 状态，不再自动变成 Ready。修改和 start/resume 分离，已完成步骤及历史记录保留。新增测试覆盖暂停后修改、调度、checkpoint 恢复仍不推进；Draft/Blocked 修改后也需显式授权继续。
2. 能力目录从实际注册工具生成，不再通过手写语义表过滤掉未知工具。只读调用者也能查看写工具契约，`available_in_current_context=false` 明确不可执行；执行器原有授权检查不变，测试实际验证写入仍被拒绝。
3. 观察输出先进行本地完整校验，失败时带原始证据、错误和拒绝内容最多修复一次；成功修复保留原错误诊断，失败不提交、不消费窗口。单元测试确认两次调用上限、原证据保留、非法来源与缺字段被拒绝。
4. 对话纠错必须提供逐字匹配的草稿引用与当前消息/历史引用；不能用旧观察作为推翻原话的证据。原文不存在、证据不齐或格式错误时保留原回复并记录失败。此检查仍是模型判断，不是外部真值认证。
5. 最终回复阶段除执行者总结外，还收到有界的实际工具证据，减少“执行者说错，整理者再肯定一次”的信息断层。超出总预算时仍保留既有直接返回执行报告的退路，不静默丢弃请求。
6. 普通对话分支补齐未知外部效果先核查、助手建议不能变用户决定、临时偏好不能变长期偏好的规则。修正 TickAction 指南中“唯一自主机制”的旧说法，明确 enabled 实际默认 true；活动指南明确事后 verify 不能充当事前批准，也不能依赖人工及时暂停来阻止下一步。
